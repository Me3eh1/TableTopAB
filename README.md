# TableTopAB (Chernobog)

Кооперативный PvE-экшен от первого лица с упором на ближний бой и орды врагов (референсы: Vermintide 2, Fatekeeper). Unreal Engine 5.8, C++ + Blueprints.

## Документация

- [`Docs/Прототип Chernobog.md`](Docs/Прототип%20Chernobog.md) — дизайн-документ прототипа (система передвижения)
- [`Docs/Прототип Chernobog — реализация передвижения.md`](Docs/Прототип%20Chernobog%20—%20реализация%20передвижения.md) — реализация: архитектура, параметры, тесты, ручной чек-лист

## Текущее состояние

Прототип системы передвижения (разделы 2–7 дизайн-дока): обычное движение, защитная стойка, уклонение (кастомный режим движения), прыжок/падение, трёхслойные состояния, выносливость, матрица коллизий. Проверен скриптовой батареей в PIE — 10/10.

Играть: открыть проект → Play (карта `L_MovementArena`). Управление: WASD, мышь, Space — прыжок, Ctrl — уклонение, ПКМ — стойка, ЛКМ — атака (заглушка).

## Структура

```
Source/TableTopAB/     C++-ядро (персонаж, компонент движения, выносливость)
Content/Input/         Enhanced Input (IMC_Default + 7 Input Action)
Content/Blueprints/    BP_TableTopCharacter, BP_TableTopGameMode
Content/Maps/          L_MovementArena — тестовый полигон
Config/                Карты и режим по умолчанию
```
