# TableTopAB (Chernobog)

Кооперативный PvE-экшен от первого лица с упором на ближний бой и орды врагов (референсы: Vermintide 2, Fatekeeper). Unreal Engine 5.8, C++ + Blueprints.

## Установка и запуск (для нового пользователя)

### Что понадобится

| Требование | Зачем |
|---|---|
| Windows 10/11 x64 | Проект настроен под Windows (DX12) |
| Видеокарта с поддержкой DirectX 12 / аппаратной трассировки лучей (DXR) | В проекте включены Lumen, Ray Tracing, Substrate (`Config/DefaultEngine.ini`) |
| [Unreal Engine 5.8](https://www.unrealengine.com/download) (через Epic Games Launcher, нужен аккаунт Epic) | Версия движка строго `5.8` (задана в `TableTopAB.uproject`) |
| [Git](https://git-scm.com/downloads) + [Git LFS](https://git-lfs.com/) | Все ассеты (`.uasset`/`.umap`) хранятся в Git LFS |
| Visual Studio 2022 (рабочая нагрузка «Разработка игр на C++») или Rider for Unreal Engine | Проект на C++ — модуль нужно скомпилировать перед запуском редактора |

Сторонних плагинов и ассетов с Fab/Marketplace нет — всё, включая контент, лежит в репозитории; плагины из `.uproject` входят в комплект движка.

### Шаги

1. **Включить Git LFS** (один раз на машине):
   ```
   git lfs install
   ```
2. **Склонировать репозиторий**:
   ```
   git clone https://github.com/Me3eh1/TableTopAB.git
   ```
   Убедиться, что ассеты скачались реально, а не как LFS-указатели: файлы в `Content/` должны весить килобайты/мегабайты, а не ~130 байт. Если нет — `git lfs pull`.
3. **Открыть `TableTopAB.uproject` двойным кликом.** Движок обнаружит отсутствие скомпилированных модулей и предложит их собрать — нажать **Yes** (нужен установленный VS/Rider). Альтернативный путь через IDE: ПКМ по `.uproject` → *Generate Visual Studio project files* → открыть `.sln` → собрать таргет `TableTopABEditor` (Development Editor | Win64) → запустить.
4. **Дождаться компиляции шейдеров** при первом открытии редактора — это нормально и занимает время.
5. Редактор сам откроет карту `L_MovementArena` (задана как стартовая). Нажать **Play** — играть.

### Возможные проблемы

- **«Missing TableTopAB module» / предложение пересобрать проект при каждом запуске** — соберите модуль через IDE (шаг 3, альтернативный путь) и запускайте редактор из IDE (F5), либо закройте редактор и пересоберите: ПКМ по `.uproject` → *Generate Visual Studio project files* → Build в VS.
- **Ассеты не открываются / весят ~130 байт** — LFS не скачан: `git lfs install` → `git lfs fetch --all` → `git lfs checkout`.
- **Долгий чёрный/белый экран при первом запуске** — идёт компиляция шейдеров, просто подождите.

## Текущее состояние

Прототип системы передвижения (разделы 2–7 дизайн-дока): обычное движение, защитная стойка, уклонение (кастомный режим движения), прыжок/падение, трёхслойные состояния, выносливость с HUD-полосой, матрица коллизий. Проверен скриптовой батареей в PIE — 10/10.

Играть: открыть проект → Play (карта `L_MovementArena`). Управление: WASD, мышь, Space — прыжок, Ctrl — уклонение, ПКМ — стойка, ЛКМ — атака (заглушка), H — крутилка параметров движения в реальном времени (не-Shipping билды).

## Структура

```
Source/TableTopAB/     C++-ядро (персонаж, компонент движения, выносливость)
Content/Input/         Enhanced Input (IMC_Default + 7 Input Action)
Content/Blueprints/    BP_TableTopCharacter, BP_TableTopGameMode
Content/Maps/          L_MovementArena — тестовый полигон
Config/                Карты и режим по умолчанию
```
